# OHMAN – Landing page

Ouvrir le dossier dans VS Code, puis lancer `index.html` avec l'extension **Live Server**.

- `index.html` : structure et contenu (catalogue = section `#produits`)
- `css/style.css` : styles (couleur principale : `--o`)
- `js/main.js` : interactions ; **remplacer le numéro WhatsApp** dans la constante `WA`
- `assets/` : photos de la maquette (`logo`, `head`, `prod`, `man`, `rock`) et du catalogue (`cat1` à `cat6`)
